# INFS2822---Programming-For-Data-Analytics

Analysed **17,600+ iced-coffee sales records** for Harbour Brew Market using Python in Jupyter Notebook, leveraging **Pandas, NumPy, Matplotlib, and Seaborn** for data analysis and visualisation. 

Conducted **data cleaning and preprocessing**, including handling missing values, removing duplicates, validating data types, and preparing datasets for analysis. 

Performed **exploratory data analysis** (EDA) to investigate the influence of factors such as temperature, seasonality, holidays, and promotional spending on sales performance. 

**Developed visualisations** including bar charts, line plots, scatter plots, and distribution analyses to identify sales trends and customer purchasing patterns. 

Collaborated within a team to interpret findings and generate **data-driven recommendations** on inventory planning, promotional timing, and marketing strategies. 

**Presented the final insights** and recommendations through a technical report and group presentation.
